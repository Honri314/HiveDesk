1. 설치

macOS다운로드 및 실행

  • 다운로드에서 HiveDesk-*.dmg를 내려받아 열고, HiveDesk 아이콘을 응용 프로그램 폴더로 드래그합니다.
  • 첫 실행 시 "개발자를 확인할 수 없음" 경고가 뜨면: 우클릭 → 열기를 한 번 눌러주면 이후엔 정상 실행됩니다. (시스템 설정 → 개인정보 보호 및 보안에서도 허용 가능)
  • 최소 사양: macOS 12+, Apple Silicon.

Windows다운로드 및 실행

  • HiveDesk Setup *.exe를 실행해 설치하거나, portable zip을 원하는 폴더에 풀어 실행합니다.
  • SmartScreen 경고 시 추가 정보 → 실행을 누릅니다.

2. Claude 계정 연동 (실제 AI 회의)

1Claude CLI 설치

터미널(명령 프롬프트)을 열고 실행:

npm install -g @anthropic-ai/claude-code

Node.js 18+ 가 필요합니다. 없다면 nodejs.org에서 먼저 설치하세요.

2로그인

claude

브라우저가 열리면 Claude 구독 계정(Pro 또는 Max)으로 로그인한 뒤 종료합니다. API 키 입력은 필요 없습니다 — 앱은 여러분의 구독 세션을 그대로 사용합니다.

3앱에서 확인

HiveDesk를 재시작하면 우측 상단 상태가 ● 연동됨(계정 이메일 표시)으로 바뀝니다. 앱의 설정 탭에서도 동일한 상태를 확인할 수 있습니다.

※ 앱은 API 키를 수집·저장하지 않습니다. 회의는 여러분의 Claude 구독 한도 안에서 로컬로 실행됩니다.

3. 연동 없이 먼저 써보기 (데모 모드)

  • 상단에 종목(BTC, 삼성전자, 하이닉스, NVDA 등)을 입력하고 회의 시작을 누르면 즉시 데모(룰베이스) 회의가 재생됩니다.
  • 픽셀 오피스에서 애널리스트 4인 → 리서치 토론 → 트레이더 → 리스크 → PM 순서로 말풍선이 이어지고, 하단 로그의 발언을 클릭하면 그 시점부터 다시 재생됩니다.
  • 실제 AI 분석을 켜려면 위 2번(Claude 연동)을 마치세요. 엔진은 설정 → 회의 엔진에서 자동/데모 강제를 바꿀 수 있습니다.

4. 자동매매 및 브로커 키 설정 (선택)

기본모의거래는 키가 필요 없습니다

전략을 모의거래 모드로 두면 브로커 키 없이 가상 현금으로 주문이 기록됩니다. 현금 부족·보유 수량 없음 시 자동 기각, 확신도 60% 미달 시 자동 홀드됩니다.

1브로커 API 키 등록

  • 자동매매 탭 → 브로커 API 키에 바이낸스(암호화폐) 또는 토스증권(한국 주식) 키를 입력하고 키 저장을 누릅니다.
  • 키는 OS 키체인(Electron safeStorage)으로 암호화되어 저장되며 앱 밖으로 전송되지 않습니다.
  • 잔고 조회 테스트로 키가 정상인지 확인하세요. 바이낸스는 테스트넷 사용(권장)을 먼저 권합니다.

2전략 추가

  • 이름·종목·시장·모드(모의/실)·자동 실행·주기(5분 이상)·승인 방식을 정해 전략 추가를 누릅니다.
  • 수동 승인(안전): 회의가 주문을 만들면 승인 큐에 쌓이고, 직접 승인해야 체결됩니다.
  • 자동 체결: 회의 결정이 그대로 주문으로 나갑니다.

3실거래 잠금 해제 (이중 안전장치)

실거래 체결에는 두 가지가 모두 필요합니다: ① 전역 킬스위치 ON, ② 전략별 실거래 잠금해제. 하나라도 꺼져 있으면 실제 주문은 절대 나가지 않습니다.

※ 실거래는 손실 위험이 사용자에게 있습니다. 먼저 모의거래로 전략을 검증한 뒤 활성화하세요.

5. 문제 해결

증상해결
상태가 미연동으로 표시됨터미널에서 claude --version 이 실행되는지 확인 → claude로 로그인 → 앱 재시작
회의가 데모로만 돌아감설정 → 회의 엔진이 자동인지 확인. Claude 구독 사용량 한도 초과 시 데모로 강등될 수 있습니다.
시세가 "합성 데이터"로 표시됨오프라인 또는 시세 서버 차단. 네트워크 확인 후 재시도하면 실시간 시세로 복귀합니다.
주문이 승인 큐에만 쌓임승인 방식이 수동 승인인 전략입니다. 큐에서 승인하거나 전략을 자동 체결로 변경하세요.
macOS에서 "손상됨" 오류터미널에서 xattr -cr /Applications/HiveDesk.app 실행 후 다시 열기
