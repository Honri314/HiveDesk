AI 에이전트들이 회의를 열어
매수 · 매도 · 홀드를 결정합니다

TradingAgents의 멀티 에이전트 파이프라인(애널리스트 → 토론 → 트레이더 → 리스크 → PM)을 Claude 구독 계정으로 구동하는 데스크톱 앱입니다. 모의거래가 기본이고, 브로커 API 키를 등록하면 실거래와 자동 매매도 가능합니다.

무료로 시작하기 설치 가이드 Discord 참여
macOS · Windows(ARM) 지원 · 설치 후 계정 연동만으로 바로 사용

회의는 이렇게 진행됩니다

애널리스트 → 토론 → 트레이더 → 리스크 → PM, 5단계 파이프라인

1STEP 1 · ANALYSTS기술·뉴스·센티먼트·펀더멘털 애널리스트 4인이 같은 시세 스냅샷(MA/RSI/MACD, 뉴스, 공포탐욕지수)을 놓고 각자 해석을 발언합니다. 관점이 다른 초기 리포트가 만들어집니다.
2STEP 2 · RESEARCH강세 리서처와 약세 리서처가 서로의 주장을 집요하게 반박합니다. 리서치 총괄이 양쪽 논거를 검증해 중재 결론을 제시하고 bull/bear 케이스를 정리합니다.
3STEP 3 · TRADER토론 결론을 근거로 트레이더가 구체적인 매매안을 제출합니다 — 진입 가격, 수량, 손절 라인, 확신도까지 플랜으로 정리됩니다.
4STEP 4 · RISK리스크 매니저가 브레이크를 밟습니다. 손절 라인, 비중 한도(현금의 20%), 과열 구간을 체크해 무리한 주문은 이 단계에서 걸러집니다.
5STEP 5 · PM FINAL포트폴리오 매니저가 최종 승인·기각을 결정합니다. 승인 시에만 주문이 체결되며, 픽셀 오피스에서 이 전 과정이 실시간으로 재생됩니다.

왜 HiveDesk인가

계정 연동만으로 AI 회의 · 브로커 키 등록 시 실거래까지

계정 로그인 연동

터미널에서 claude에 로그인하면 끝. 앱은 여러분의 Claude 구독 한도 안에서 회의를 진행하며, API 키를 수집하거나 저장하지 않습니다.

데모 모드

Claude 연동 전에도 동일한 파이프라인을 규칙 기반 페르소나로 체험할 수 있습니다. 회의 구조와 판정 흐름을 먼저 확인하세요.

픽셀 오피스

회의실·경영실·부서별 워크스테이션·키친이 있는 회사 오피스에서 회의가 재현됩니다. 리서치 발언 때는 회의실로 집합하고, 발언을 클릭하면 그 시점부터 재생합니다.

실시간 시세

Yahoo Finance·Binance 공개 시세로 국내주식·코인·글로벌 티커(삼성전자, BTC, NVDA 등)를 지원합니다. 오프라인이면 합성 데이터로 자동 전환됩니다.

투명한 기록

모든 회의 턴·결정·주문이 로컬 SQLite에 기록됩니다. 포트폴리오 탭에서 현금·포지션·평가손익을 실시간으로 확인하세요.

바이낸스·토스증권 연동 실거래

자동매매 탭에서 브로커 API 키를 등록하면 활성화됩니다. 전역 킬스위치 + 전략 잠금해제 이중 안전장치, 수동 승인 큐가 기본입니다.

안전 규칙 모의거래

기본값은 모의거래입니다. 실제 주문 없음 · 현금 부족 시 자동 기각 · 확신도 60% 미달 시 자동 홀드. 모드는 전략별로 선택합니다.

자주 묻는 질문

API 키 없이 쓸 수 있나요?

네. API 키를 수집하지 않고 Claude 구독 계정 로그인만으로 동작합니다. 연동 전에도 데모 모드로 전체 파이프라인을 체험할 수 있습니다.

실제 주문이 나가지 않을까 걱정돼요

기본값은 모의거래입니다. 실거래는 ①전역 킬스위치 ON ②전략별 잠금해제 두 가지가 모두 켜져야 가능하고, 수동 승인 방식이면 승인 큐에서 직접 눌러야 체결됩니다.

어떤 종목을 지원하나요?

바이낸스 상장 코인(BTC 등)과 토스증권 연동 한국 주식(삼성전자, 하이닉스 등), Yahoo Finance 시세의 글로벌 티커(NVDA 등)를 지원합니다.

회의 품질은 뭐가 달라지나요?

데모 모드는 규칙 기반 페르소나로 구조를 보여주고, Claude 연동 시 실제 LLM이 시세를 해석해 발언합니다. 사용량은 구독 등급 한도 안에서 처리됩니다.
